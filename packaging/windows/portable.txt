SelfPhoto Editor portable mode

While this file sits next to photocraft.exe, SelfPhoto Editor keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the SelfPhoto EditorData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move SelfPhoto Editor with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photocraft for settings
and %LOCALAPPDATA%\Photocraft\Recovery for crash-recovery autosaves. If SelfPhoto EditorData can't be
written (for example on a read-only drive), SelfPhoto Editor says so and uses those folders instead.
